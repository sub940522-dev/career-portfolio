# 서버 운영 · CI/CD

- 시기: 공간정보 SI 기업(지오앤) 입사 2개월 차부터
- 배경: 서버 담당자 퇴사로 공백이 생겨 직접 맡아 학습하며 운영
- 규모: 대형 서버랙 2대, 물리 서버 4대, 서비스 5~7개 (연구소와 공동 사용, 타사 시스템 포함)
- 기술: Linux, Apache, Tomcat, GitLab, Jenkins, Docker

## 담당 업무

포트 관리, 외부 접근 허용, 배포, 모니터링, 계정·권한, 인증서 대응. 같은 서버를 쓰는 타사 개발자와 배포·포트 조율.

## CI/CD 도입

- Before: 서버에 직접 접속해 Tomcat 중지 → FTP로 파일 교체 → 수동 재기동
- After: GitLab Webhook + Jenkins로 커밋 즉시 자동 빌드·배포. 배포 시간이 크게 단축

## 장애 대응

- Problem: 자동 배포 이후 다른 개발자가 잘못된 빌드를 올리면 서버가 죽은 채로 배포됨
- Decision: 이전 버전으로 즉시 되돌리는 롤백 절차 마련 + 이를 위한 주기적 백업 설정
- Result: 빌드 오류가 나도 빠르게 서비스 복구

## Docker

- 직접 설치보다 컨테이너로 올리는 쪽이 관리가 쉽고 환경 차이로 인한 문제가 적어 활용
- 안전보건공단 AI 프로젝트의 최종 산출물을 Docker 이미지로 패키징해 제출
- 관심: Kubernetes
