# 충청남도 노선버스 운행정보시스템(BIS) 구축

- 기간: 2021.07 – 2022.03 (신입 첫 프로젝트, 시범운영까지)
- 역할: 수집서버 ↔ 웹 실시간 송수신 인터페이스, 사용자·관리자 웹, 충청남도청 관리 사이트 개발
- 기술: Java, TCP Socket, 전자정부프레임워크, JSP
- 규모: 버스 약 30대 (단말 설치는 협력사, 관리 참여)

## 구성

버스 단말기 → 수집서버 → DB → 웹 · 정류장 안내기

## 수행

- 단말기 위치 정보를 실시간으로 받아 웹에 보내는 TCP 소켓 인터페이스를 Java로 개발
- 사용자용·관리자용 웹, 도청 관리 사이트 개발
- 시범운영 기간에 직접 버스에 탑승해 실시간 수신·표시 검증

## 문제 해결

- 양방향 통신 협업: 명세서의 바이트 길이대로 전문이 오는지, 양측 포트가 열렸는지 단계별 점검. 함수·처리 방식을 상대 업체와 통일해 안정성 확보
- 현장 변수: Wi-Fi 끊김, 시동만 켠 버스와 실제 운행 버스의 구분(이동만 해도 운행으로 판단되는 문제)을 현장 탑승 테스트로 확인하며 보정
- TCP·소켓 통신은 처음이었지만 자료 조사와 상대 업체 지원을 받아 직접 구현
