# 인천문화재단 통합 홈페이지 구축 · 유지보수

- 기간: 구축 2024.09 – 2025.05 / 유지보수 2025.05 – 2025.10
- 범위: 인천 소재 문화정보 사이트 18개를 하나로 통합
- 담당: CMS 관리자, 게시판, 프로그램 예약·신청, 회원, 기존 데이터 이관 전반

## 수행

- 데이터 이관: 재단과 협의해 일정 기간 이전 데이터는 제외하는 등 이관 기준을 정하고 필요한 데이터만 추려 전처리
- 웹 접근성 인증·보안 점검 대응
- 통합 사이트를 대상으로 열린 인천시 대학생 해킹대회를 문제없이 마침

## 문제 해결

- Problem: 보통 사이트 담당자는 1~2명인데, 18개 사이트를 합치면서 18명의 담당자 요청이 동시에 들어옴
- Decision: 담당자별 요청을 정리해 우선순위를 두고 하나씩 대응 (세부 방식은 본인 확인 필요)
- Result: 구축 후 유지보수까지 안정적으로 운영
