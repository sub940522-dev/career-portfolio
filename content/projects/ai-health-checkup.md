# AI를 활용한 특수건강검진 DB 직종 재분류

- 기간: 2024.07 – 2024.11
- 발주: 안전보건공단
- 역할: AI 모델 개발 전담 (Python, 단독 수행 / PM 검수)
- 기술: Python, XGBoost, RandomForest, GPU 가속, Docker (최종 산출물 패키징)

## 문제

특수건강검진 대상자의 10년 이상 누적 데이터 대부분에서 직종·산업현장 정보가 누락된 채 관리되고 있었음.

## 수행

- 정답 데이터 약 10만 건으로 모델 학습 → 1,800만 건 이상의 누락 직종·산업현장 예측
- 입력 피처: 사업장명, 업종 코드, 유해인자, 공정명, 직종 등
- 전처리가 전체 작업의 약 70%
  - 유해인자 종류가 매우 많아 원-핫 인코딩 차원이 커짐
  - 텍스트 정제, 클래스 불균형 처리
- RandomForest와 XGBoost(GPU 가속) 비교 → XGBoost 채택, 정확도 약 92%

## 결과물

- 예측 시스템 + 보고서, Docker 이미지로 패키징해 제출
- 1차: 신규 유입 데이터(월 1만 건 이하)에 직종을 바로 채워 앞으로는 정상 관리되게 함
- 2차: 그동안 쌓인 누락 데이터도 순차 예측해 보완
