# 개인 프로젝트 · AI 리뷰 콘텐츠 자동 제작 파이프라인

- 시기: 2026.10
- 기술: Python, python-telegram-bot, Gemini / OpenAI / Claude API, Gemini TTS, FFmpeg, Pillow, YouTube Data API(OAuth), Kakao Local API, Selenium

## 무엇을 만들었나

음식 사진·영상과 짧은 메모만 보내면, 쇼츠 영상 기획부터 렌더링·업로드까지 자동으로 처리하는 파이프라인. 같은 재료로 네이버 블로그 글을 게시하는 도구도 함께 운용.

## 흐름

1. 접수 (Telegram 봇): 사진·영상과 메모를 받아 작업 폴더로 저장. 메모를 칸별로 파싱. 허용된 사용자만 사용
2. 검사·분류: dHash로 중복 사진, 흔들림·어두움 자동 검사. EXIF 촬영 시각으로 점심/저녁/술집 분류, GPS로 Kakao 장소 검색
3. 기획: AI가 대본(씬·자막·제목·해시태그) 작성
4. 검수 루프: 규칙 검사(길이, 말 빠르기, 메모에 없는 가격, 없는 사진 사용) + 검수 AI 채점. 기준 미달이면 피드백을 반영해 최대 2회 재작성
5. 렌더링: TTS 나레이션을 무음 구간 기준으로 자막과 맞추고, FFmpeg로 1080×1920 영상 두 가지(나레이션판, 음악판) 생성
6. 업로드: 버튼 확인 후 YouTube Data API로 업로드
7. 블로그: Selenium으로 네이버 블로그 글·사진 게시, 완료 글은 자동 이동

## 설계 포인트

- AI 공급자 추상화: Gemini·GPT·Claude를 같은 함수(ask_json)로 호출. 무료 한도 초과 시 다른 모델로 대체하거나 재시도 예약
- 사실성 규칙: 메모에 없는 맛·가격은 쓰지 않도록 규칙 검사와 AI 검수를 이중으로 둠
- 스타일 가이드를 텍스트 파일로 분리해 재시작 없이 말투·구성을 바꿀 수 있게 함
